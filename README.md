# STAR REPLICA: AUTOMA
## 自己複製特化型2D自動化工場・宇宙艦隊シミュレーション (Commercial Release Edition)

🌐 **ブラウザで今すぐプレイ (GitHub Pages):**  
👉 **https://wak-shogo.github.io/ReplicaAutomata-/**

未開の惑星へ1機の自己複製種機体（Seed Unit）として降下。手動採掘とドローン合体から始まり、惑星上にブループリントホログラムを指定して自律建築ドローン群とともに自動化工場ラインを建造。コンベアドラッグ敷設による実体物流網を整え、宇宙軌道へ大量の仲間を射出してスウォーム艦隊を1万体規模まで拡大。

恒星を中心に母星を物理公転する月、長楕円軌道を描く彗星、降着円盤を纏う超重力ブラックホール、激しいパルスビームを放つ中性子星、小惑星帯など、本物の天体力学（万有引力・ケプラー運動）で運行する大宇宙を舞台に、各天体から固有の希少資源（プラズマ、ヘリウム3、重水素氷、暗黒物質、中性子物質）を採掘。大規模宇宙構造物（メガストラクチャー）を建造しながら敵性レプリカ要塞コアを制圧・星系を解放する独立2Dシミュレーションゲームです。

---

## 1. 起動方法
1. `run_game.bat` をダブルクリックして起動します。
2. または、Godot 4.7 (`H:\Godot_v4.7-stable_win64.exe\Godot_v4.7-stable_win64.exe`) で本フォルダを開き、F5キーで実行します。

## 2. 宇宙天体 ＆ 固有採掘資源 (Celestial Bodies & Exotic Resources)

星系内のすべての天体は静止しておらず、**本物のニュートン万有引力・ケプラー天体力学**に基づいてリアルタイムに公転・自転・運行しています。プレイヤー機体およびスウォーム艦隊（⛏️ HARVESTドクトリン）は、各天体に接近して直接採掘レーザーを照射し、固有の希少資源を獲得できます。

| 天体種別 | 天体名 | 軌道・物理特性 | 固有採掘資源 | 特殊効果 |
| :--- | :--- | :--- | :--- | :--- |
| **母星** | **ORIGIN-PRIME** | プレイヤー降下星。半径620pxの岩石惑星。地下に4種鉱脈。 | 鉄 (Fe), 銅 (Cu), チタン (Ti), 珪素 (Si) | 工場基地の拠点・大気圏ホバリング |
| **月 (衛星)** | **LUNA-PRIME** | **母星の周囲をリアルタイムに物理公転**（軌道半径880px）。地表から見上げると月が昇り沈む。 | **ヘリウム3 (He-3)** | 核融合・スウォーム推進動力 |
| **恒星** | **HELIOS-PRIME** | 星系中心上部の超巨大な灼熱太陽。コロナ・プロミネンス自転。 | **純粋太陽プラズマ (Plasma)** | ソーラー発電効率が爆発的に急上昇 |
| **ブラックホール** | **GARGANTUA-ZERO** | 漆黒の事象の地平面・超高速回転するネオン降着円盤・相対論的ジェット。超強力な重力引力。 | **暗黒物質 (Dark Matter)** | 時空歪曲・メガストラクチャー最終素材 |
| **彗星** | **NEOWISE-OMEGA** | 恒星を焦点とする超長楕円ケプラー軌道。近日点で超高速移動し、太陽風で青白いロングな尾を引く。 | **重水素氷 (Ice / Gas)** | 推進剤・超冷却材 |
| **中性子星** | **PULSAR-X** | 超高密度青白核・磁場ループ・両極から回転放射される鋭い相対論的パルスビーム。 | **中性子縮退物質 (Neutronium)** | 極限硬度装甲 |
| **小惑星帯** | **ASTEROID-BELT** | 母星の外縁を周回する18個の小惑星リング。 | 高純度鉄 (Fe), シリコン (Si), チタン (Ti) | 宇宙空間での手軽な資源補給 |

## 3. 直感的操作 ＆ ゲームパッド完全対応 (Controls & Minimalist UX)

画面内の邪魔な文字を極限まで排除した**ノンバーバル・サイバーUI**を採用。マウス・キーボードはもちろん、**家庭用ゲームコントローラー（Xbox / PS / Switch / Steam Deck）1本で全操作がストレスフリーに完結**します。

| 動作 | キーボード＆マウス | ゲームパッド (Joypad) | 説明 |
| :--- | :--- | :--- | :--- |
| **移動・ホバリング** | `W / A / S / D` / 矢印 | **左スティック** / 十字キー | 惑星重力とスラスターによる滑らかな360度推進 |
| **採掘レーザー** | `左クリック` (長押し) | **RT (R2)** または **Aボタン** | 地下鉱脈または宇宙天体（月・彗星・特異点等）へ自動照準採掘 |
| **ブループリント配置** | `左クリック` | **RT (R2)** または **Aボタン** | 指定地点にホログラムを配置（建築ドローンが自動飛来） |
| **コンベア連続ドラッグ** | `左ボタンドラッグ` | **RT押しっぱなし移動** | 地表に沿ってコンベアラインを流れるように敷設 |
| **解体・キャンセル** | `右クリック` / `[0]` | **LT (L2)** または **Bボタン** | 施設の解体ブループリント指定 / ツール選択解除 |
| **ツール切替** | `[1]〜[0]` 数字キー | **LB / RB (L1 / R1)** | 建設ツールを左右に順繰り選択 |
| **ビルドモード切替** | `Tab キー` | **Yボタン** / **Backボタン** | ツールバー展開・ホログラムグリッドの表示切替 |
| **ドローン合体** | `B キー` | **Xボタン (□)** | 小型プリントドローンを自機に合体（作業ドローン数増加） |
| **自機カメラ追従** | `Space キー` | **L3 / R3 (スティック押し込み)** | カメラを瞬時に自機中央へスムーズリセット |
| **全体マップ切替** | `M キー` | **Back / Select ボタン** | 星系全体のマクロ軌道全景（深宇宙マップ）へ切り替え |
| **自由カメラパン** | `右ボタンドラッグ` | マウス右ドラッグ | 惑星地表や宇宙空間を自由にスクロール探索 |
| **スムーズズーム** | `マウスホイール` / `Z / X` | ホイール / ボタン | 0.16x 〜 2.4x のシームレスズーム |
| **スウォーム方針切替** | 上部アイコンクリック | **D-Pad (十字キー)** | ⛏️ 採掘回収(下) / 🧬 増殖(左右) / ⚔️ 総攻撃(上) |
| **クイックセーブ** | `F5 キー` | **Start / Menu ボタン** | `user://star_replica_save.json` へ瞬時保存（3分オートセーブ付） |
| **クイックロード** | `F9 キー` | — | 直前のセーブ状態から瞬時に再開 |

## 4. 自動回帰テストスイート
以下のコマンドで全機能（ブループリント、建築ドローン、コンベアドラッグ、タレット防衛、メガストラクチャー、星系マクロマップ、ボス戦、月/ブラックホール天体採掘）の自動テストとスクリーンショット撮影（全9フェーズ）を実行できます：
```powershell
& "H:\Godot_v4.7-stable_win64.exe\Godot_v4.7-stable_win64_console.exe" --path "." -- --run-tests
```
実行結果のスクリーンショットは `docs/art/test_01_blueprint_hologram.png` 〜 `test_09_blackhole_singularity.png` に自動保存されます。
