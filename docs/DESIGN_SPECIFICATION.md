# STAR REPLICA: AUTOMA (自己複製特化型2D工場・宇宙艦隊シミュレーション)

## 1. プロジェクト概要
- **名称**: STAR REPLICA: AUTOMA (仮称: Star Replica 2D Swarm Edition)
- **保管場所**: `C:/Users/wakazaki shogo/git/StarReplica-Automa/`（完全独立プロジェクト）
- **基本コンセプト**:
  プレイヤーは1機の自己複製種機体（Seed Unit）として未開の惑星へ降下。手動採掘から始まり、小型プリントドローンを機体にアタッチして自らを巨大マシーンへと拡張。惑星上にFactorio並みに硬派な自動化工場ライン（採掘・精錬・組立・大型プリンタ）を構築し、自己同型機を大量複製してマスドライバーから宇宙へ連続射出。宇宙空間で最大1万体規模の自己複製スウォーム艦隊を指揮し、資源ロジスティクスを確立しながら敵性レプリカに占拠された銀河を奪還する。

## 2. ビジュアル＆アートディレクション精査結果
AI画像生成およびプロシージャルピクセルアートによる画面精査に基づき、以下のビジュアル指針を確定：
1. **解像度・スタイル**:
   - 16-bit風の高精細レトロピクセルアート（トップダウン見下ろし型）。
   - ダークスペース・濃紺の惑星地表タイルをベースに、シアン（エネルギー/情報）、アンバー（金属/熱）、パープル（レア資源/チタン）、オレンジ（銅/導線）、レッド（敵性レプリカ）のハイコントラスト・ネオンパレット。
2. **工場フロアの視認性**:
   - コンベアベルト・インサータ・配線・パイプがごちゃごちゃになっても一目で流れが分かる幾何学デザイン。
3. **主人公マシンの合体拡張演出**:
   - 中央のコアユニットの周囲に、クラフトした「小型プリントドローン」がカシャカシャと物理的にアタッチ。ドローン数が増えるほど機体サイズが巨大化し、複数本の採掘ビームや建築ビームを同時に放てる多関節重機スウォームへと進化。
4. **マスドライバー射出演出**:
   - 工場ラインで製造されたレプリカ機体がコンベアで発射台へ運ばれ、超電導レールを青白い電磁スパークとともに宇宙へドカンと撃ち出されるダイナミックな発射エフェクト。
5. **1万体スウォームの宇宙・軌道ビュー**:
   - 画面右上（またはシームレスなズームアウト）の軌道モニターで、1万個の輝く自律ユニットが星々の中を群れ（Boids / Swarm）となって整然と飛び交い、小惑星を採掘・敵艦隊へプラズマ斉射する圧倒的スペクタクル。

## 3. ゲームループとコアシステム

### フェーズ1: 目覚めと自己拡張（Chassis Expansion）
- 惑星上に初期シード機体として着陸。
- 手動レーザーで微量の鉱石（鉄 Fe、シリコン Si、銅 Cu）を採掘。
- 「小型プリントドローン（Fabricator Drone）」を造形し、自機にドッキング。
- ドローンが接続されるたびに：
  - 建設可能な施設Tierがアンロック（ドローン0機: 手動クラフトのみ → 1機: コンベア/採掘機 → 3機: 精錬炉/組立機 → 5機以上: 大型プリンタ/マスドライバー）。
  - 同時採掘レーザー数・作業範囲が拡大。

### フェーズ2: 惑星上オートメーション基地（Planetary Industrial Grid）
- **採掘機（Automated Miner）**: 鉱脈から鉱石を自動掘削。
- **コンベアベルト（Transport Belt）**: 各種鉱石や中間部品の搬送ライン。
- **インサータ/アーム（Inserter）**: 施設間のアイテム搬送・装填。
- **電気精錬炉（Smelter）**: 鉄板、シリコンウェハー、銅線へ精錬。
- **加工組立機（Assembler）**: 集積回路、フレーム、センサー、推進剤を製造。
- **大型プリンタ（Macro Replicator / Planetary Shipyard）**:
  - 主人公と同型の「自己複製探査機（Replica Probe）」をライン生産する巨大プラント。
- **軌道マスドライバー（Orbital Mass Driver）**:
  - 完成した機体をコンベアで受領し、高圧チャージして宇宙軌道へ高速射出！

### フェーズ3: 1万体自己複製艦隊＆資源ロジスティクス（10,000 Swarm Logistics）
- 射出された機体は軌道上の「スウォーム艦隊（Swarm Fleet）」へ自動合流（最大10,000機まで同時管理・シミュレーション）。
- **ロジスティクス倉庫（Depot / Warehouse Directive）**:
  - プレイヤーが特定の地上倉庫や軌道デポに「要求資源（例: チタン 2,000、イリジウム 500）」を設定。
  - スウォーム内の担当ドローン部隊が自動で小惑星帯や別拠点へ飛び、採掘して当該倉庫へ直接ピストン輸送。
- **自己複製艦隊の自律方針（Fleet Doctrines）**:
  - `資源回収専念`: 指定倉庫を満杯にするまで採掘。
  - `宇宙現場での自己増殖`: 宇宙空間の小惑星資源をその場で消費し、分裂・複製してスウォームを幾何級数的に倍増。
  - `星系防衛 / 迎撃`: 侵入してくる敵性レプリカの迎撃。
  - `侵攻作戦`: 敵要塞・汚染巣窟へ1万機で一斉突入。

### フェーズ4: 巨大構造物・大型決戦兵器＆宇宙奪還
- 宇宙エレベーター、ダイソンリング、軌道プラズマ要塞、超大型レールガンなどの超巨大構造物を建設。
- 敵性レプリカ（Corrupted Swarm）のコア星系へ侵攻し、銀河全域の支配権を取り戻す。

## 4. パフォーマンス設計（1万体ユニットの最適化）
- **Godot 4 MultiMeshInstance2D & Array-based ECS Simulation**:
  - 個々のドローンを重いNode2Dにせず、位置・速度・ターゲットIDを連続メモリ配列（PackedVector2Array）で管理。
  - 10,000体の描画はGPUインスタンシング（MultiMesh2D）で一括Draw Call。
  - 60FPS常時キープを実現。
